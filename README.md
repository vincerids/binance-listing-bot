# Binance Listing Monitor & Telegram Bot

Скрипт на Node.js для отслеживания новых листингов (спотовых и фьючерсных) на бирже Binance с отправкой уведомлений в Telegram.

## 🛠 Стек технологий
- **Node.js**
- **Axios** (для запросов к API Binance и Telegram)
- **dotenv** (для безопасного хранения токенов)
- **Node.js Test Runner** (встроенные тесты)

## ⚙️ Как это работает
Скрипт каждые 5 секунд запрашивает список доступных торговых пар на Binance. При обнаружении новой пары (которой не было в предыдущем запросе), формируется сообщение и отправляется в указанный Telegram-чат. Бот поддерживает команды `/start`, `/stop` и `/status`.

## 🚀 Как запустить локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/vincerids/binance-listing-bot.git

2. Установите зависимости:
   ```bash
   npm install

3. Создайте файл .env в корне проекта (по примеру .env.example) и добавьте ваши данные:
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен
   TELEGRAM_CHAT_ID=ваш_id

4. Запустите скрипт:
   ```bash
   node binance-new-listings.js

## Тесты
Проект покрыт тестами. Чтобы запустить их, выполните:
   ```bash
   node --test
```
## Безопасность
Файл .env добавлен в .gitignore и не попадает в репозиторий. Токены хранятся только локально.
